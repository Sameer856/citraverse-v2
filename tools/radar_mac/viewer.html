1 · Connect the dev kit

Connect its CH347 USB port. Close the Windows radar tool and any other app using this kit.

PA6 is the radar’s Notify pin. Its CH347 GPIO number depends on the dev-kit wiring. Select a GPIO only after confirming that mapping.

2 · Start radar output

This optional step checks the firmware version, then applies the known radar-analysis SPI profile. It stops on an unacknowledged command. It does not flash firmware.

If the kit is already configured and running over SPI, skip this step.
